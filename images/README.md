# 이미지 추가 안내

현재 저장소에는 실제 서비스 화면과 상장 이미지가 없습니다. 가짜 이미지나 임시 캡처를 만들지 않고, 개인정보와 팀원 동의를 확인한 실제 자료만 추가합니다.

README에는 존재하지 않는 이미지를 직접 표시하지 않았으므로 현재 상태에서도 깨진 이미지가 보이지 않습니다.

## 수상 증빙 추가 방법

1. 상장 또는 공식 수상 자료의 공개 권한을 확인합니다.
2. 원본은 별도 보관하고 공개용 사본에서 개인정보를 가립니다.
3. 수상명은 사용자 제공 정보와 같은 **우수상**인지 확인합니다.
4. 다음 경로로 저장합니다.

```text
images/award.jpg
```

5. 파일이 실제로 추가된 뒤 README의 `수상 및 증빙` 항목 아래에 다음 Markdown을 넣습니다.

```markdown
![SW 잡브릿지-DAY 통합프로젝트 발표회 우수상 증빙](images/award.jpg)
```

## 개인정보 제거 체크리스트

- 이름 공개 범위에 팀원 전원이 동의했는가
- 전화번호, 이메일과 생년월일을 가렸는가
- 주소, 주민등록번호와 서명을 가렸는가
- 브라우저 탭, 북마크, 계정 프로필 사진이 노출되지 않는가
- AWS 계정 번호, 리소스 ARN, 버킷명과 RDS 주소가 보이지 않는가
- API 키, GitHub Secrets, 환경변수 값이 보이지 않는가
- 실제 사용자 닉네임과 감정 기록을 익명화했는가
- 관리자 화면의 신고 내용과 대상 사용자를 익명화했는가

## 캡처 원칙

- 데모 계정을 사용하고 실제 사용자 데이터를 캡처하지 않습니다.
- 한 화면에 보여줄 기능을 하나로 제한합니다.
- 브라우저 개발자 도구, 주소 표시줄과 운영 도메인은 필요할 때만 포함합니다.
- 모바일 캡처와 데스크톱 캡처를 섞기보다 같은 비율로 통일합니다.
- 긴 페이지는 핵심 영역을 잘라 사용하되 기능의 맥락이 사라지지 않게 합니다.
- 이미지에 설명을 직접 많이 넣기보다 README 캡션으로 설명합니다.

> 화면 및 수상 증빙 이미지는 개인정보 확인 후 추가 예정입니다.
